# DCFA Test Data Editor

Custom editor for DCFA test data files used in SBIS testing system.

## Features

- Visual editing of DCFA test data files
- Tabbed interface for blocks and tasks
- Specialized editors for different task types (TpTsk)
- Bit-field editor for instructions (TpTsk=4)
- Template editor (TpTsk=2)

## Usage

1. Open a `.dcfa` or `.txt` file
2. Right-click and select "Open With..." → "DCFA Editor"
3. Edit the data using the visual interface
4. Save the file (Ctrl+S)

## Requirements

- VSCode 1.75.0 or higher
